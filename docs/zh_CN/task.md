# Sharpa Wave 手内旋转

## 任务目标

控制手部关节目标位置，让物体在手中绕指定轴持续旋转，同时保持稳定抓握。
奖励鼓励旋转，并约束物体平移、手部姿态偏移和控制消耗。
每个 episode 最长 20 秒；物体离开初始抓取的高度范围时，按掉落结束。

## 环境设置

当前使用 MuJoCo 仿真。每次重置从稳定抓取缓存中选择手部关节位置和物体位姿。
包内已提供缓存；更换模型或抓取策略后，可以重新生成。

物体包含 0.8、0.9、1、1.1、1.2、1.3、1.4、1.5 八种固定尺度。
每个并行环境使用其中一种尺度，并读取对应缓存。

训练时随机化物体质量、重心、摩擦、重力方向和关节控制增益，并施加外力扰动。
策略观测包含关节与触觉信息，触觉可配置平滑、延迟和噪声。
这些变化用于训练策略适应不同物体和传感条件。

## Teacher 与 student

PPO、APPO、FlashSAC 共用 HORA teacher/student 流程：

1. **Teacher** 使用可测观测和仿真特权信息（如质量、摩擦）学习旋转策略。
2. **Student** 从历史观测估计 teacher 的特权表示，再使用继承的策略输出动作。
3. **评估** 在固定场景中检查旋转速度、存活时间和掉落率。

Student 推理只需要可测观测及其历史，不需要仿真特权信息。
三种算法使用各自的训练预算，比较结果时需同时考虑实际采样量和耗时。
